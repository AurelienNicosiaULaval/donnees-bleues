# Extension Shiny future

Ce dossier est réservé à une future application Shiny.

Idées possibles :

- filtrer le catalogue par thème, niveau ou score zero waste dataset;
- afficher les fiches sous forme de cartes;
- proposer des parcours pédagogiques;
- exporter une sélection de jeux de données pour un plan de cours.

Le MVP principal ne dépend pas de Shiny.
