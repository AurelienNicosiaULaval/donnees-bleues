Jeu de données zéro déchet

Cadre pédagogique

Un bon jeu de données ne s’épuise pas après une seule activité.

Le principe zéro déchet aide à choisir des données qui servent réellement l’apprentissage : comprendre le contexte, préparer les données, visualiser, modéliser, interpréter, communiquer et discuter les limites.

Voir la grille Explorer le catalogue

Score maximal

30

10 dimensions, chacune cotée de 0 à 3.

L’idée centrale

Un jeu de données zéro déchet est une source pédagogique dont on extrait plusieurs apprentissages cohérents, sans forcer des usages artificiels.

Le problème

En classe, un fichier peut être techniquement correct mais pédagogiquement pauvre si le contexte est flou, si l’unité statistique est obscure ou si les limites ne peuvent pas être discutées.

La réponse

La grille rend les choix explicites avant de construire une fiche, une activité courte, une activité longue ou un projet complet.

Contexte

Pourquoi ce cadre existe

Données bleues vise à transformer des sources québécoises en matériel de cours directement utilisable. Le défi n’est pas seulement de trouver des données ouvertes. Le défi est de trouver des données qui soutiennent une progression pédagogique complète.

Avant la classe

Le cadre aide à décider si une source mérite le temps de préparation nécessaire : documentation, licence, téléchargement, nettoyage, variables principales et limites d’interprétation.

Pendant la classe

Il permet de choisir des données qui rendent visibles les opérations statistiques importantes, plutôt que de noyer les personnes étudiantes dans une complexité technique sans objectif clair.

Après la classe

Il favorise des ressources qui peuvent être reprises, adaptées, prolongées et discutées dans plusieurs cours ou à plusieurs niveaux.

Objectif

Maximiser le rendement pédagogique sans masquer la réalité des données.

Le but n’est pas de privilégier les gros fichiers. Un petit jeu de données peut être excellent s’il permet d’enseigner plusieurs opérations avec un coût cognitif raisonnable. À l’inverse, une source volumineuse peut être peu utile si sa structure, sa provenance ou ses limites empêchent de poser des questions interprétables.

Parcours

Un même jeu de données, plusieurs apprentissages

Le cadre sert à repérer les sources qui peuvent accompagner une vraie progression, de la première lecture du fichier jusqu’à la communication des résultats.

Importer

Lire les fichiers, comprendre le format et conserver un script reproductible.

Nettoyer

Traiter les types de variables, les valeurs manquantes, les libellés et les unités.

Explorer

Décrire les distributions, repérer les anomalies et formuler des questions.

Visualiser

Construire des graphiques ou des cartes qui clarifient la structure des données.

Modéliser

Utiliser une méthode raisonnable pour le niveau visé, avec validation et prudence.

Communiquer

Produire un résultat interprétable, sourcé et reproductible.

Évaluation

La grille zéro déchet

Chaque dimension est cotée de 0 à 3. Le score maximal est 30. Cette grille est un outil de conception pédagogique interne au projet, pas une mesure scientifique validée.

Contexte

Contexte québécois

Le jeu de données est lié à un territoire, une institution ou un enjeu québécois.

Entrée

Accessibilité pédagogique

Les personnes étudiantes peuvent comprendre rapidement ce que les lignes et les variables représentent.

Provenance

Qualité documentaire

La source, la licence, la structure et les variables principales sont suffisamment documentées.

Préparation

Potentiel de nettoyage

Le jeu permet d’enseigner des opérations réalistes de préparation des données.

Graphiques

Potentiel de visualisation

Les variables se prêtent à des graphiques, cartes ou tableaux utiles pour apprendre.

Résumés

Statistique descriptive

Les indicateurs numériques produits ont une interprétation claire.

Incertitude

Potentiel d’inférence

Le jeu permet de poser des questions de comparaison, d’incertitude ou de généralisation avec prudence.

Modèles

Potentiel de modélisation

Une modélisation raisonnable peut être formulée pour le niveau pédagogique visé.

Limites

Discussion éthique

Le jeu ouvre une discussion sur les biais, la mesure, les usages, les populations ou le territoire.

Durabilité

Réutilisabilité

La même source peut soutenir plusieurs modules, niveaux, activités ou projets.

Lecture du score

Ce que le total veut dire

Le score sert à guider une décision de conception. Il ne remplace pas le jugement pédagogique.

0 à 10

Potentiel limité ou usage très ciblé.

11 à 20

Bon jeu pour une activité.

21 à 25

Très bon jeu pour plusieurs modules.

26 à 30

Jeu structurant pour un cours ou un projet complet.

Une source, plusieurs angles d’enseignement

Implémentation

Calcul reproductible du score

La fonction compute_zero_waste_score() calcule le total, le pourcentage et l’interprétation à partir des dix dimensions du cadre.

source("R/utils_zero_waste.R")

scores <- c(
  contexte_quebecois = 3,
  accessibilite_pedagogique = 3,
  qualite_documentaire = 2,
  potentiel_nettoyage = 2,
  potentiel_visualisation = 3,
  potentiel_statistique_descriptive = 3,
  potentiel_inference = 2,
  potentiel_modelisation = 2,
  potentiel_ethique = 2,
  reutilisabilite = 3
)

compute_zero_waste_score(scores)

Limites

Ce que le cadre ne doit pas faire

La grille ne doit pas transformer une décision pédagogique en classement définitif. Elle sert à expliciter les raisons d’un choix, à documenter les compromis et à repérer les sources qui méritent un investissement de préparation.

Il ne faut pas forcer tous les apprentissages avec le même jeu. Si une source ne permet pas d’enseigner une notion de façon pertinente, le meilleur choix est de le reconnaître et d’utiliser un autre exemple.
