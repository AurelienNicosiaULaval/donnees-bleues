Pourquoi ce jeu est intéressant

Ce jeu est très riche pour l’enseignement : il relie essences, mesures dendrométriques, arrondissement, emplacement, localisation et qualité des données. Il permet de travailler des questions concrètes de foresterie urbaine avec une vraie source municipale.

Il est aussi utile parce qu’il contient des difficultés réalistes : gros fichier, plusieurs ressources, valeurs manquantes, dates aberrantes et mise en garde officielle sur la précision des localisations.

Question d’analyse : quelles essences d’arbres publics dominent l’inventaire, et quelles limites faut-il vérifier avant de cartographier ou comparer les arrondissements?

La description officielle indique que les données portent sur les arbres municipaux du domaine public, incluant des arbres de rue et hors rue. Elle signale aussi que les localisations spatiales peuvent être imprécises ou pas à jour et que certains arrondissements n’indiquent pas les arbres de parcs.

Ce que représente une ligne

Une ligne représente un arbre public inventorié dans le fichier consolidé. La ligne contient des informations d’arrondissement, d’emplacement, d’essence, de diamètre, de dates et de coordonnées.

Une ligne n’est pas une mesure écologique complète, un arbre privé, ni une preuve que le couvert arboré est mesuré de façon uniforme dans tous les arrondissements.

Lecture statistique

Une analyse prudente suit cet ordre :

  1. vérifier si la question porte sur les arbres de rue, les arbres hors rue, les parcs ou l’ensemble consolidé;
  2. inspecter les valeurs manquantes avant de comparer les arrondissements;
  3. traiter les dates de plantation et de relevé comme des variables à valider;
  4. compter les essences avec regroupement explicite des libellés manquants;
  5. cartographier avec une note sur la précision des localisations;
  6. éviter de conclure sur le couvert arboré ou la biodiversité sans données complémentaires.

Les données permettent de décrire un inventaire municipal riche. Elles ne suffisent pas, seules, à estimer la canopée, la santé des arbres ou l’équité environnementale.

Activité courte

En 30 à 45 minutes, compter les essences principales dans un arrondissement et nommer une limite de couverture.

Activité longue

En 2 à 3 heures, produire une carte agrégée ou un échantillon cartographique, un tableau de valeurs manquantes et une analyse par arrondissement.

Code R minimal

À exécuter depuis la racine du projet.

# Load libraries
library(dplyr)
library(ggplot2)
library(readr)

# Download and prepare official CSV resource
source("datasets/arbres-publics-montreal/preparation.R")

# Import prepared data
arbres <- read_csv(
  "data/processed/arbres-publics-montreal/arbres_publics_montreal.csv",
  show_col_types = FALSE
)

# Summarise top species in one borough
resume_essences <- arbres |>
  filter(arrondissement == "Rosemont - La Petite-Patrie") |>
  count(essence_fr, sort = TRUE) |>
  slice_head(n = 10)

resume_essences

# Plot top species
ggplot(resume_essences, aes(x = reorder(essence_fr, n), y = n)) +
  geom_col() +
  coord_flip() +
  labs(
    x = "Essence",
    y = "Nombre d'arbres",
    title = "Essences les plus fréquentes dans Rosemont - La Petite-Patrie",
    subtitle = "Inventaire public municipal; vérifier la couverture avant comparaison"
  )

Limites et précautions

  • La source officielle signale que certaines localisations peuvent être imprécises ou pas à jour.
  • Dans certains arrondissements, les arbres de parcs ne sont pas indiqués selon la description officielle.
  • Les dates de plantation sont manquantes pour 134 514 lignes.
  • Les dates préparées plausibles reposent sur une règle de nettoyage, pas sur une validation administrative indépendante.
  • Comparer les arrondissements exige de tenir compte de la superficie, de la densité, de la couverture d’inventaire et des arbres privés.

Extensions

  • Comparer les essences dominantes entre deux arrondissements.
  • Étudier les valeurs manquantes par type d’emplacement.
  • Construire un graphique du DHP par essence fréquente.
  • Produire une carte en échantillonnant les points ou en les agrégeant par grille.
  • Joindre des données de superficie ou de population pour construire un indicateur contextualisé.
