Pourquoi ce jeu est intéressant

Ce jeu met les étudiants devant une source environnementale québécoise réelle, volumineuse et imparfaite. Il est idéal pour enseigner les séries temporelles, les valeurs manquantes, les résumés journaliers et la visualisation prudente d’un phénomène environnemental.

La fiche utilise la ressource officielle 2025 du RSQAQ. Le fichier brut contient des mesures horaires par station et par contaminant. La préparation locale produit un résumé journalier station-contaminant afin de garder les analyses rapides, reproductibles et adaptées à un laboratoire pédagogique.

Ce que représente une ligne

Dans le CSV officiel, une ligne représente une station et une heure publiée. Les contaminants sont en colonnes. Une même ligne peut donc contenir plusieurs valeurs de contaminants ou plusieurs valeurs manquantes.

Dans la table préparée pour la fiche, une ligne représente plutôt un résumé journalier pour une station et un contaminant : nombre d’heures valides, moyenne, médiane, 95e percentile et maximum.

Une ligne n’est pas un épisode de pollution, une exposition individuelle, un diagnostic sanitaire ou une mesure causale. C’est un résumé descriptif des valeurs publiées pour une station, un jour et un contaminant.

Ces journées sont des points de départ pour l’exploration. Elles ne suffisent pas à identifier une cause. Pour interpréter un épisode, il faut ajouter du contexte : météo, feux de forêt, transport régional des polluants, sources locales et validation instrumentale.

Lecture statistique

Une analyse prudente suit cet ordre :

  1. choisir une année et un contaminant;
  2. vérifier le nombre d’heures valides par jour;
  3. résumer par station et par date;
  4. visualiser la série temporelle avant de classer les épisodes;
  5. éviter de mélanger les contaminants sans unité commune;
  6. distinguer valeur élevée, épisode environnemental et cause possible.

Le résumé journalier est pratique pour l’enseignement, mais il masque les variations intra-journalières. Pour une question plus fine, il faut retourner aux mesures horaires.

Activité courte

En 60 à 90 minutes, choisir le PM2.5 et repérer les journées les plus élevées en imposant un minimum d’heures valides. Les étudiants doivent expliquer pourquoi un classement descriptif ne suffit pas à conclure sur la cause.

Activité longue

En 2 à 3 heures, construire un tableau de bord exploratoire par station, contaminant et période. Le livrable doit inclure les décisions de nettoyage, les valeurs manquantes, les graphiques et une section de limites.

Code R minimal

À exécuter depuis la racine du projet.

# Load libraries
library(dplyr)
library(ggplot2)
library(readr)

# Prepare official 2025 CSV resource
source("datasets/qualite-air-horaire/preparation.R")

# Import prepared daily summaries
air_jour <- read_csv(
  "data/processed/qualite-air-horaire/resume_journalier_contaminants_2025.csv",
  show_col_types = FALSE
)

# Focus on PM2.5 days with at least 18 valid hourly values
pm25 <- air_jour |>
  filter(contaminant_source == "PM2.5-T640", n_heures_valides >= 18)

pm25 |>
  arrange(desc(moyenne)) |>
  select(date, station_name, n_heures_valides, moyenne, maximum) |>
  slice_head(n = 10)

ggplot(pm25, aes(x = date, y = moyenne, group = station_id)) +
  geom_line(alpha = 0.25, linewidth = 0.3) +
  labs(
    title = "Moyennes journalières de PM2.5 par station, 2025",
    x = "Date",
    y = "Moyenne journalière des valeurs publiées"
  ) +
  theme_minimal()
Résultat visible

Aucune table préparée locale n’est disponible pour exécuter un aperçu tabulaire fiable. Les exemples qui téléchargent une source externe restent non évalués pendant le rendu du site afin de garder les fiches stables.

Limites et précautions

  • La fiche conserve les valeurs publiées par contaminant sans harmoniser les unités.
  • Les valeurs manquantes varient fortement selon les contaminants et les stations.
  • Un résumé journalier peut masquer des pics horaires.
  • Une valeur élevée n’identifie pas automatiquement une cause.
  • Les comparaisons entre stations doivent tenir compte de la couverture horaire.
  • Les données sont descriptives; une analyse sanitaire ou réglementaire demanderait un cadre méthodologique plus spécialisé.

Extensions

  • Comparer les résultats avec un seuil minimal de 18, 20 ou 24 heures valides.
  • Produire un calendrier de chaleur pour une station.
  • Comparer PM2.5 et O3 sans les placer sur la même échelle.
  • Ajouter des données météo pour explorer les épisodes.
  • Préparer une note publique qui sépare observation, hypothèse et conclusion.
