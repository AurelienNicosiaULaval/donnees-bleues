Pourquoi ce jeu est intéressant

Ce jeu est utile parce qu’il force une décision statistique simple, mais essentielle : avant de compter, il faut savoir ce qu’une ligne représente. La source regroupe des établissements, des installations, des liens école-immeuble, des immeubles et des sièges sociaux. Une analyse correcte commence donc par le choix explicite de la ressource et de l’unité statistique.

Il se prête bien à un cours d’introduction en science des données : importation de données ouvertes, harmonisation de fichiers, variables catégorielles, coordonnées géographiques, tableaux de fréquences, cartes et limites d’interprétation.

Ce que représente une ligne

La table préparée contient une ligne pour chaque ligne source conservée dans l’une des 9 ressources CSV. Ce n’est pas une table de personnes, ni une table d’élèves, ni une table unique d’établissements scolaires.

Variable Rôle
source_resource Identifiant court de la ressource d’origine
resource_label Nom lisible de la ressource d’origine
network_category Catégorie de réseau : public, privé, collégial, universitaire ou gouvernemental
unit_kind Unité statistique de la ligne
source_row Numéro de ligne dans le fichier source

Cette distinction est le coeur pédagogique de la fiche. Par exemple, une ligne de public_ecole correspond à un lien école-immeuble, tandis qu’une ligne de public_immeuble correspond à un immeuble. Les deux fichiers peuvent être utiles, mais ils ne répondent pas à la même question statistique.

Lecture statistique

L’analyse recommandée commence par trois filtres.

  1. Choisir une ressource avec source_resource.
  2. Vérifier l’unité statistique avec unit_kind.
  3. Utiliser has_region ou has_coordinates selon la question.

Un exemple valide : cartographier les Écoles publiques et expliquer que chaque point représente un lien école-immeuble. Un exemple fragile : additionner directement les 9 ressources pour dire combien il existe d’établissements au Québec. Ce deuxième calcul mélange plusieurs unités statistiques et peut compter des objets institutionnels liés entre eux.

Activité courte

En 30 à 45 minutes, choisir une seule ressource, tracer les points et rédiger une phrase qui décrit précisément l’unité statistique utilisée.

Activité longue

En 2 à 3 heures, produire un portrait territorial prudent : carte, tableau par réseau, analyse des régions manquantes et limites sur l’accessibilité.

Code R minimal

À exécuter depuis la racine du projet.

# Load libraries
library(dplyr)
library(ggplot2)
library(readr)

# Prepare official CSV resources
source("datasets/etablissements-enseignement/preparation.R")

# Import prepared table
etablissements <- read_csv(
  "data/processed/etablissements-enseignement/etablissements_enseignement_quebec.csv",
  show_col_types = FALSE
)

# Check units before counting
etablissements |>
  count(source_resource, resource_label, unit_kind, sort = TRUE)

# Map one coherent resource
ecoles_publiques <- etablissements |>
  filter(source_resource == "public_ecole")

ggplot(ecoles_publiques, aes(x = longitude, y = latitude)) +
  geom_point(alpha = 0.35, size = 0.8) +
  coord_quickmap() +
  labs(
    x = "Longitude",
    y = "Latitude",
    title = "Écoles publiques du Québec",
    subtitle = "Chaque point représente un lien école-immeuble dans la ressource source"
  )

Limites et précautions

  • Les 9 ressources ne doivent pas être additionnées sans réflexion sur l’unité statistique.
  • Une coordonnée ne mesure pas l’accessibilité réelle d’un service.
  • Les 7 847 lignes sans région administrative peuvent biaiser une comparaison régionale si elles sont exclues sans justification.
  • Les noms, municipalités et régions sont traités comme des libellés sources, pas comme des identifiants administratifs normalisés.
  • Pour étudier l’accès scolaire, il faut joindre d’autres données : population, distance, transport, capacité ou effectifs.
