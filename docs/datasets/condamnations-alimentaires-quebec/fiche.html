  • Nettoyer la variable d'amende et comparer les montants selon le type d'infraction.

Pourquoi ce jeu est intéressant

Ce jeu place les personnes étudiantes dans une situation proche du journalisme de données : une liste publique de condamnations, des noms d’établissements, des descriptions textuelles, des dates, des montants d’amende et un besoin immédiat de prudence. Il est utile pour enseigner les tableaux de fréquences, le nettoyage de chaînes, la conversion de montants et la communication responsable de résultats publics.

La fiche porte sur la version pédagogique UlavalSSD::listecondamnation, utilisée dans l’aventure 3 de STT-1100. Cette version est fixe, alors que la ressource officielle Données Québec est mise à jour régulièrement. Les deux doivent donc être distinguées dans toute analyse.

Ce que représente une ligne

Une ligne de la version pédagogique représente une condamnation publiée dans le jeu UlavalSSD::listecondamnation. La ligne décrit un exploitant, un établissement ou une raison sociale, une infraction, un lieu, des dates et un montant d’amende.

L’unité statistique n’est pas un restaurant au sens général. C’est une condamnation publiée. Un même établissement peut apparaître plus d’une fois, et une fréquence élevée dans la table ne donne pas un taux de risque sans connaître le nombre total d’établissements comparables.

Lecture statistique

La première analyse doit être descriptive. Les questions solides portent sur la composition de la table : types d’établissements, montants d’amende, délais administratifs et catégories d’infraction.

Trois erreurs doivent être évitées :

  • parler de “risque” par type d’établissement sans dénominateur fiable;
  • conclure qu’un lieu est dangereux à partir d’une condamnation publique isolée;
  • confondre la date d’infraction, la date de jugement et la date de publication.

Dans UlavalSSD 0.2.0, les quatre modalités observées de Type_etablissement sont liées aux restaurants. Le CSV officiel courant est plus large et contient aussi des catégories comme l’épicerie, la pâtisserie, la ferme laitière et le bien-être animal. Cette différence justifie de nommer précisément la version analysée.

Activité courte

En 60 à 90 minutes, demander aux personnes étudiantes d’identifier l’unité statistique, de produire un tableau de fréquences de Type_etablissement, de convertir Amende en variable numérique et de rédiger une conclusion qui refuse explicitement l’interprétation en taux de risque.

Activité longue

En 2 à 3 heures, demander un court article de données reproductible. Le texte doit inclure un tableau, un graphique, un nettoyage documenté de Amende, une comparaison de dates et une note de prudence sur les noms et adresses.

Questions pédagogiques possibles

  1. Quelle est l’unité statistique : établissement, infraction ou condamnation?
  2. Pourquoi un nombre de condamnations n’est-il pas un taux de risque?
  3. Quelle différence y a-t-il entre date d’infraction, date de jugement et date de publication?
  4. Pourquoi faut-il convertir Amende avant de calculer une médiane?
  5. Comment regrouper des catégories textuelles sans cacher une information importante?
  6. Quelles informations faut-il éviter de mettre en évidence inutilement dans une visualisation publique?
  7. Pourquoi la version UlavalSSD et le CSV officiel ne doivent-ils pas être mélangés?
  8. Quelle phrase de conclusion serait descriptive sans être sensationnaliste?

Code R minimal

library(dplyr)
library(ggplot2)
library(readr)
library(stringr)
library(UlavalSSD)

condamnations <- listecondamnation |>
  mutate(
    across(c(Date_infraction, Date_jugement, Date_publication), as.Date),
    amende_num = parse_number(Amende, locale = locale(grouping_mark = " ")),
    ville_montreal = str_detect(
      Adresse_lieu_infraction,
      regex("MONTREAL|MONTRÉAL", ignore_case = TRUE)
    ),
    delai_infraction_jugement_jours = as.integer(Date_jugement - Date_infraction),
    delai_jugement_publication_jours = as.integer(Date_publication - Date_jugement)
  )

condamnations |>
  count(Type_etablissement, sort = TRUE)

condamnations |>
  summarise(
    n = n(),
    amende_mediane = median(amende_num),
    amende_max = max(amende_num),
    delai_median_infraction_jugement = median(delai_infraction_jugement_jours),
    delai_median_jugement_publication = median(delai_jugement_publication_jours)
  )

condamnations |>
  count(Type_etablissement, sort = TRUE) |>
  ggplot(aes(x = reorder(Type_etablissement, n), y = n)) +
  geom_col() +
  coord_flip() +
  labs(
    x = "Type d'établissement",
    y = "Nombre de condamnations dans la version pédagogique",
    title = "Condamnations par type d'établissement"
  )

Limites et précautions

  • La version UlavalSSD est une version pédagogique fixe; elle ne remplace pas le CSV officiel courant.
  • Les fréquences sont des nombres de condamnations publiées, pas des taux d’infraction.
  • Il manque un dénominateur fiable : nombre d’établissements par type, exposition temporelle, volume d’activité.
  • Les noms, raisons sociales et adresses sont publics, mais doivent être traités avec retenue dans un contexte pédagogique.
  • Les catégories textuelles peuvent changer entre la version pédagogique et la ressource officielle.
  • Les délais entre infraction, jugement et publication sont administratifs; ils ne mesurent pas directement un risque sanitaire.

Extensions

  • Extension intro : produire un tableau de fréquences de Type_etablissement.
  • Extension nettoyage : convertir Amende et vérifier les montants extrêmes.
  • Extension dates : comparer les délais entre infraction, jugement et publication.
  • Extension communication : rédiger un court article qui distingue observation descriptive et interprétation abusive.
