Mini-projet - Rapport méthodologique sans diffusion des lignes

En classe, cette activité sert à…

Cette activité sert à travailler les notions suivantes : Provenance, Validation, Rapport reproductible, Droits de réutilisation, Communication prudente à partir d’une question située dans le contexte suivant : Éducation supérieure. Elle demande aux étudiantes et étudiants de répondre à la question directrice suivante : Comment produire un rapport utile sur une source institutionnelle privée sans créer une diffusion publique non autorisée?

Élément Information
Durée 2-3 heures
Niveau Intermédiaire
Usage recommandé Mini-projet guidé
Préparation enseignant Vérifier les droits de diffusion avant la séance; utiliser seulement les résumés publics et ne pas publier les lignes de données.
Production attendue Un court rapport reproductible avec contexte, tableau ou graphique, interprétation et limites.
Données data/processed/ulaval-programmes-cours/resume_ulaval_programmes_cours.csv

Objectifs d’apprentissage

  • Travailler Provenance.
  • Travailler Validation.
  • Travailler Rapport reproductible.
  • Travailler Droits de réutilisation.
  • Nommer au moins une limite d’interprétation.

Données utilisées

Source : Université Laval, Bureau de la qualité des programmes. Licence : Aucune licence ouverte explicite identifiée pour les données sources; réutilisation publique à valider auprès de l’Université Laval ou par avis juridique.. Fichier principal pour l’activité : data/processed/ulaval-programmes-cours/resume_ulaval_programmes_cours.csv

Préparation enseignante

  • Vérifier les droits de diffusion avant la séance; utiliser seulement les résumés publics et ne pas publier les lignes de données.
  • Fichier préparé : data/processed/ulaval-programmes-cours/resume_ulaval_programmes_cours.csv.
  • Script de préparation : datasets/ulaval-programmes-cours/preparation.R.
  • Point à surveiller : Demander un rendu local ou un rapport public sans lignes privées. Vérifier que le texte ne suggère pas une approbation officielle.

Consignes

  1. Importer resume_ulaval_programmes_cours.csv ou exécuter datasets/ulaval-programmes-cours/preparation.R si le fichier est absent.
  2. Identifier ce que représente une ligne du fichier.
  3. Produire un tableau ou un graphique adapté à la question directrice.
  4. Rédiger une interprétation courte qui distingue description et explication.
  5. Nommer au moins une limite méthodologique ou une information absente.

Résultat attendu

Un court rapport reproductible avec contexte, tableau ou graphique, interprétation et limites. La production doit aussi contenir une phrase sur l’unité statistique et une phrase sur une limite de la source.

Questions

  1. Quelle est l’unité statistique utilisée dans cette activité?
  2. Quelle transformation ou agrégation est nécessaire avant de répondre à la question?
  3. Quelle information manque pour aller plus loin?
  4. Quelle conclusion serait trop forte avec ces seules données?
  5. Comment formuler une conclusion prudente à partir du résultat obtenu?

Déroulé suggéré

  1. Cadrer la source, la licence et l’unité statistique.
  2. Préparer ou importer les données.
  3. Produire un premier résumé descriptif.
  4. Construire la visualisation ou le tableau principal.
  5. Rédiger l’interprétation et les limites.

Limites à faire nommer

  • Demander un rendu local ou un rapport public sans lignes privées. Vérifier que le texte ne suggère pas une approbation officielle.
  • Si une variable ou un dénominateur nécessaire n’est pas disponible dans les données, l’écrire explicitement plutôt que l’inférer.

Contexte

Cette activité demande de produire un mini-rapport Quarto local sur une intégration institutionnelle privée. Le rapport doit documenter la méthode, les contrôles et les limites, sans redistribuer les CSV privés ni les PDF sources.

Question directrice

Comment produire un rapport utile sur une source institutionnelle privée sans créer une diffusion publique non autorisée?

Livrables

  1. Une section décrivant le statut indépendant et non officiel de la compilation.
  2. Une section sur les fichiers validés, avec lignes attendues et observées.
  3. Une section sur les clés uniques et les champs de provenance.
  4. Une section sur les droits et les éléments non vérifiés.
  5. Un court tableau public de synthèse, sans lignes individuelles.
  6. Une conclusion qui indique ce qui peut être montré publiquement et ce qui doit rester local.

Structure suggérée

1. Statut et droits

Utiliser explicitement les formulations suivantes :

  • compilation indépendante et non officielle;
  • aucune licence ouverte explicite identifiée;
  • Je ne sais pas pour l’autorisation de republication publique à grande échelle.

2. Validation

Lire les fichiers de résumé produits par preparation.R :

  • resume_ulaval_programmes_cours.csv;
  • resume_fichiers_ulaval.csv;
  • resume_controles_ulaval.csv;
  • resume_droits_ulaval.csv.

3. Synthèse publique

Présenter seulement des comptes et des contrôles : nombre de fichiers, nombre de lignes, présence des champs de provenance, unicité des clés. Ne pas publier de listes de programmes, de cours ou de lignes GES.

Appui R minimal

library(dplyr)
library(readr)

source("datasets/ulaval-programmes-cours/preparation.R")

resume <- read_csv(
  "data/processed/ulaval-programmes-cours/resume_ulaval_programmes_cours.csv",
  show_col_types = FALSE
)

fichiers <- read_csv(
  "data/processed/ulaval-programmes-cours/resume_fichiers_ulaval.csv",
  show_col_types = FALSE
)

droits <- read_csv(
  "data/processed/ulaval-programmes-cours/resume_droits_ulaval.csv",
  show_col_types = FALSE
)

resume |>
  select(source_found, validation_status, n_core_expected_rows, n_ges_expected_rows)

fichiers |>
  count(phase, wt = observed_rows, name = "lignes_observees")

droits

Critères d’évaluation suggérés

  • Exactitude du statut institutionnel et juridique.
  • Absence de lignes privées et de PDF sources dans le rapport public.
  • Qualité des contrôles de validation.
  • Clarté sur ce qui est vérifié et ce qui ne l’est pas.
  • Reproductibilité du code.
  • Prudence du langage.
