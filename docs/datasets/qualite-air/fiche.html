Pourquoi ce jeu est intéressant

Ce jeu décrit l’infrastructure de mesure du Réseau de surveillance de la qualité de l’air du Québec. Il ne donne pas directement les concentrations de polluants. Cette distinction en fait une bonne fiche pédagogique : les étudiants doivent comprendre ce qu’une donnée représente avant de produire une carte ou un graphique.

Le fichier permet de travailler l’importation d’un CSV officiel, les dates d’ouverture et de fermeture, les valeurs manquantes, les catégories de milieu, les coordonnées géographiques et les limites d’un répertoire de stations.

Question d’analyse : comment décrire la couverture du réseau de stations sans la confondre avec la qualité de l’air mesurée?

Les métadonnées CKAN indiquent que le fichier contient l’identification et la localisation des stations du RSQAQ. Elles précisent aussi que seules les stations liées aux jeux de données horaires continues et séquentielles sont incluses, et que les stations de l’île de Montréal sont exclues.

La page du MELCCFP indique que le réseau produit des données sur la qualité de l’air ambiant au moyen de stations réparties sur le territoire québécois. Elle présente aussi plusieurs objectifs du réseau, dont le suivi à long terme, la diffusion d’information à la population et la préservation de l’historique des données.

Ce que représente une ligne

Une ligne représente une station de mesure incluse dans le répertoire public RSQAQ. La ligne contient un identifiant, un nom, une région administrative codée, une municipalité, un type de milieu, des dates d’ouverture et de fermeture, puis des coordonnées.

Une ligne n’est pas une observation de pollution, une mesure horaire, un indice de qualité de l’air, ni une estimation d’exposition de la population.

Lecture statistique

Une analyse prudente suit cet ordre :

  1. vérifier que l’unité est la station;
  2. distinguer les métadonnées de stations des mesures de polluants;
  3. définir explicitement le statut préparé à partir de date_fermeture;
  4. résumer les stations par type de milieu ou région;
  5. cartographier les points sans interpréter la carte comme une carte de pollution;
  6. joindre les mesures horaires seulement si la question porte sur les concentrations.

Les données permettent de décrire le répertoire des stations du RSQAQ. Elles ne permettent pas, seules, de comparer la qualité de l’air entre régions ou municipalités.

En 30 à 45 minutes, compter les stations par type de milieu et discuter la règle utilisée pour identifier les stations sans date de fermeture.

En 2 à 3 heures, produire un court rapport sur la couverture territoriale et temporelle du réseau, avec une carte de points et une section explicite sur les limites.

Code R minimal

À exécuter depuis la racine du projet.

# Load libraries
library(dplyr)
library(ggplot2)
library(readr)

# Prepare official CSV resource
source("datasets/qualite-air/preparation.R")

# Import prepared data

  "data/processed/qualite-air/rsqaq_stations.csv",
  show_col_types = FALSE
)

# Summarise by type of environment
resume_types <- stations |>
  group_by(type_milieu, station_sans_date_fermeture) |>
  summarise(stations = n(), .groups = "drop")

resume_types

# Plot station counts
ggplot(
  resume_types,
  aes(x = type_milieu, y = stations, fill = station_sans_date_fermeture)
) +
  geom_col(position = "dodge") +
  labs(
    x = "Type de milieu",
    y = "Nombre de stations",
    fill = "Sans date de fermeture",
    title = "Stations RSQAQ par type de milieu",
    subtitle = "Répertoire des stations, pas mesures de pollution"
  )

Limites et précautions

  • Le fichier décrit les stations, pas les concentrations de polluants.
  • Les stations situées sur l’île de Montréal sont exclues selon les métadonnées CKAN.
  • Une station sans date de fermeture ne doit pas être interprétée sans vérification comme une station administrativement active.
  • Une station fermée ne signifie pas nécessairement une absence de surveillance actuelle dans une région.
  • Une carte de points peut donner une fausse impression de couverture si elle n’est pas accompagnée d’une discussion méthodologique.
  • Pour analyser la qualité de l’air, il faut joindre des mesures de contaminants, par exemple les données horaires continues.
