Laboratoire - Phosphore total par station

En classe, cette activité sert à…

Cette activité sert à travailler les notions suivantes : Séries temporelles agrégées, Statistique descriptive, Visualisation, Unités de mesure à partir d’une question située dans le contexte suivant : Qualité de l’eau. Elle demande aux étudiantes et étudiants de répondre à la question directrice suivante : Comment décrire l’évolution du phosphore total médian dans une station de suivi?

Durée 30-45 minutes

Préparation enseignante

  • Vérifier que data/processed/suivi-rivieres-fleuve/stations_qualite_eau_aires.csv est disponible; aucune collecte en direct n’est nécessaire pour lancer l’activité.
  • Fichier préparé : data/processed/suivi-rivieres-fleuve/stations_qualite_eau_aires.csv.

  • Point à surveiller : Faire expliciter l’unité statistique et l’unité mg/l dans la conclusion.

Résultat attendu

Un tableau ou graphique descriptif accompagné de trois phrases d’interprétation prudente. La production doit aussi contenir une phrase sur l’unité statistique et une phrase sur une limite de la source.

Questions

  1. Quelle est l’unité statistique utilisée dans cette activité?
  2. Quelle transformation ou agrégation est nécessaire avant de répondre à la question?
  3. Quelle information manque pour aller plus loin?
  4. Quelle conclusion serait trop forte avec ces seules données?
  5. Comment formuler une conclusion prudente à partir du résultat obtenu?

Limites à faire nommer

  • Faire expliciter l’unité statistique et l’unité mg/l dans la conclusion.
  • Si une variable ou un dénominateur nécessaire n’est pas disponible dans les données, l’écrire explicitement plutôt que l’inférer.

Contexte

Cette activité utilise la fiche Suivi de la qualité de l’eau du fleuve et des rivières. Le but est de produire une première lecture temporelle du phosphore total médian pour une station de suivi, en gardant les unités et les limites de la source visibles.

Objectifs d’apprentissage

  • Importer une table préparée à partir d’un ZIP officiel.
  • Identifier l’unité statistique d’une observation environnementale agrégée.
  • Choisir une station avec suffisamment d’années d’observation.
  • Produire un graphique temporel lisible.
  • Formuler une conclusion prudente.

Question directrice

Comment décrire l’évolution du phosphore total médian dans une station de suivi?

Consignes

  1. Exécuter datasets/suivi-rivieres-fleuve/preparation.R.
  2. Importer data/processed/suivi-rivieres-fleuve/stations_qualite_eau_aires.csv.
  3. Choisir une station avec au moins 20 années non manquantes pour ptot_med_mgl.
  4. Produire un graphique de ptot_med_mgl selon annee.
  5. Ajouter un titre qui nomme la station ou le cours d’eau.
  6. Rédiger une conclusion de 5 à 8 lignes qui mentionne l’unité, l’unité de mesure et une limite.

Appui R minimal

library(dplyr)
library(ggplot2)
library(readr)

source("datasets/suivi-rivieres-fleuve/preparation.R")

stations <- read_csv(
  "data/processed/suivi-rivieres-fleuve/stations_qualite_eau_aires.csv",
  show_col_types = FALSE
)

stations_longues <- stations |>
  filter(!is.na(ptot_med_mgl)) |>
  count(no_bqma, hydronyme, name = "n_annees") |>
  filter(n_annees >= 20) |>
  arrange(desc(n_annees))

station_choisie <- stations_longues$no_bqma[1]

stations |>
  filter(no_bqma == station_choisie) |>
  ggplot(aes(x = annee, y = ptot_med_mgl)) +
  geom_line() +
  geom_point() +
  labs(
    x = "Année de fin de suivi",
    y = "Phosphore total médian (mg/l)",
    title = paste("Station", station_choisie)
  )

Pistes de solution

Une bonne réponse précise que chaque point est une statistique agrégée pour une station et une année de fin de suivi. Elle évite d’affirmer qu’une variation annuelle est causée par un facteur particulier sans analyse supplémentaire.
