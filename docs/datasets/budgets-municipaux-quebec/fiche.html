Pourquoi ce jeu est intéressant

Ce jeu est utile pour enseigner un réflexe central en science des données : lire la documentation avant d’analyser. Le titre courant parle souvent de finances municipales, mais le CSV préparé ici ne contient pas un budget détaillé par postes de dépenses. Il décrit plutôt le profil financier 2024-2025 des municipalités locales, avec des indicateurs issus du sommaire du rôle d’évaluation foncière 2025.

La valeur pédagogique est forte parce que les étudiants doivent relier trois tables : les municipalités, les classes de population et le dictionnaire des postes FIALX. On peut donc travailler l’importation de données ouvertes, le passage au format long, les ratios, les valeurs manquantes et la communication prudente.

Question d’analyse : comment les indicateurs de richesse foncière varient-ils selon la taille et la région des municipalités?

La page Québec.ca indique que le profil financier permet d’obtenir des données financières et fiscales, des ratios et des comparaisons avec différents groupes de municipalités. Elle précise aussi que certaines catégories de territoires ne sont pas publiées dans les profils, notamment les villages nordiques et plusieurs territoires autochtones.

Ce que représente une ligne

Dans la table municipale préparée, une ligne représente une municipalité locale ou une agglomération publiée dans le fichier PF-2024-2025.csv.

Dans la table longue préparée, une ligne représente une combinaison municipalité x indicateur financier. Cette version est plus adaptée aux graphiques et aux exercices de nettoyage, car le dictionnaire officiel des postes donne le sens de chaque code FIALX.

Une ligne n’est pas un budget municipal complet, une dépense annuelle, une dette totale, ni une mesure de qualité de gestion municipale.

Les valeurs manquantes ne doivent pas être traitées automatiquement comme des zéros. Par exemple, l’absence de communauté métropolitaine indique surtout que la municipalité n’appartient pas à une communauté métropolitaine publiée dans cette colonne.

Lecture statistique

Une analyse prudente suit cet ordre :

  1. vérifier que l’unité est la municipalité ou l’agglomération publiée;
  2. lire le dictionnaire des postes avant de renommer les variables FIALX;
  3. distinguer population totale, nombre de municipalités et classes de population;
  4. calculer des résumés descriptifs par classe ou par région;
  5. repérer les valeurs manquantes;
  6. éviter de présenter les indices comme des mesures de performance municipale.

Les données permettent de décrire des profils financiers publiés par le MAMH. Elles ne permettent pas, seules, d’expliquer pourquoi une municipalité a un profil foncier différent, ni d’évaluer la qualité de son administration.

Concepts enseignables

  • importation d’un CSV officiel;
  • documentation des variables avec un dictionnaire séparé;
  • passage du format large au format long;
  • regroupements par classe de population;
  • médianes et valeurs extrêmes;
  • comparaison descriptive;
  • valeurs manquantes;
  • interprétation prudente d’indices administratifs.

Code R minimal

À exécuter depuis la racine du projet.

# Load libraries
library(dplyr)
library(ggplot2)
library(readr)

# Prepare official CSV resources
source("datasets/budgets-municipaux-quebec/preparation.R")

# Import prepared data
municipalites <- read_csv(
  "data/processed/budgets-municipaux-quebec/profil_financier_municipalites_2025.csv",
  show_col_types = FALSE
)

# Summarise by population class
resume_classes <- municipalites |>
  group_by(classe_population) |>
  summarise(
    municipalites = n(),
    population_totale = sum(population, na.rm = TRUE),
    part_residentielle_mediane = median(FIALX02005, na.rm = TRUE),
    part_industrielle_commerciale_mediane = median(FIALX02006, na.rm = TRUE),
    .groups = "drop"
  )

resume_classes

# Visualise one indicator
ggplot(
  municipalites |> filter(!is.na(classe_population), !is.na(FIALX02005)),
  aes(x = classe_population, y = FIALX02005)
) +
  geom_boxplot(fill = "#8FC7D9", color = "#1F3B57", outlier.alpha = 0.35) +
  coord_flip() +
  labs(
    x = "Classe de population",
    y = "Part résidentielle publiée",
    title = "Part résidentielle de l'évaluation imposable uniformisée",
    subtitle = "Profil financier 2024-2025, données de 2025"
  )

Limites et précautions

  • Le CSV préparé ici provient du sommaire du rôle d’évaluation foncière 2025.
  • Le fichier ne contient pas un budget municipal détaillé par postes de dépenses.
  • Les noms de municipalités peuvent changer dans le temps.
  • Certaines catégories de territoires ne sont pas publiées dans les profils financiers.
  • Les classes de population simplifient fortement la structure municipale.
  • Les ratios et indices doivent être interprétés avec le dictionnaire officiel des postes.
  • Les comparaisons par région ou classe sont descriptives.

Extensions

  • Comparer les résultats avec et sans les municipalités de 100 000 habitants et plus.
  • Faire une table longue et produire une facette par indicateur.
  • Joindre une géographie régionale pour produire une carte agrégée.
  • Comparer le profil 2025 à une année antérieure en réutilisant le même script.
  • Rédiger une note méthodologique expliquant pourquoi le fichier ne mesure pas directement les dépenses.
