Pourquoi ce jeu est intéressant

Ce jeu est très fort pour enseigner la cartographie responsable. Les points sont concrets, liés à des inondations réelles, mais ils ne représentent pas une zone inondée complète. Une bonne analyse doit donc distinguer un marqueur ponctuel, un événement, un niveau maximal atteint et une observation faite lors d’une visite.

Il permet aussi d’introduire des notions rarement visibles dans les jeux d’introduction : précision horizontale, précision verticale, altitude mesurée, provenance, valeurs manquantes et communication du risque.

Ce que représente une ligne

Une ligne représente un marqueur ponctuel de niveau d’eau observé lors d’un événement d’inondation. Une ligne n’est pas une maison touchée, une municipalité touchée, une zone inondée ni une mesure continue du niveau d’eau.

Le jeu distingue deux types d’observation.

Code Interprétation pédagogique Lignes
MAX Niveau maximal atteint lors de l’inondation 1 195
ACT Niveau observé lors de la visite sur le terrain 305

La source explique que les niveaux maximaux peuvent être indiqués par des délaissés de crue, c’est-à-dire des traces ou matières déposées au début de la décrue. Les marqueurs sont ensuite localisés et altimétrés sur le terrain.

Lecture statistique

Le jeu est descriptif et spatial. Une analyse correcte commence par une question limitée :

  1. choisir une période ou un événement;
  2. distinguer MAX et ACT;
  3. cartographier les points comme des marqueurs;
  4. tenir compte des erreurs horizontales et verticales;
  5. éviter de présenter les points comme une délimitation de zone inondée.

Les résultats sont utiles pour explorer où des niveaux d’eau ont été documentés. Ils ne suffisent pas à estimer la fréquence des inondations, la population exposée ou les dommages.

Concepts enseignables

  • données spatiales ponctuelles;
  • événement extrême;
  • précision de mesure;
  • valeurs manquantes;
  • variable catégorielle;
  • altitude et unités;
  • cartographie exploratoire;
  • communication responsable du risque.

Activité courte

En 30 à 45 minutes, cartographier les marqueurs, colorer par type d’observation et écrire deux limites d’interprétation.

Activité longue

En 2 à 3 heures, produire un mini-rapport avec carte, tableau par année, comparaison MAX/ACT, valeurs manquantes et note de communication du risque.

Code R minimal

À exécuter depuis la racine du projet.

# Load libraries
library(dplyr)
library(ggplot2)
library(readr)

# Prepare official CSV resource
source("datasets/niveaux-eau-inondation/preparation.R")

# Import prepared data
niveaux <- read_csv(
  "data/processed/niveaux-eau-inondation/niveaux_eau_inondation.csv",
  show_col_types = FALSE
)

# Count observation types
niveaux |>
  count(type_obs, type_observation, sort = TRUE)

# Map points
ggplot(niveaux, aes(x = long_wgs84, y = lat_wgs84, color = type_obs)) +
  geom_point(alpha = 0.65, size = 1.2) +
  coord_quickmap() +
  labs(
    x = "Longitude",
    y = "Latitude",
    color = "Type",
    title = "Marqueurs ponctuels de niveaux d'eau lors d'inondations",
    subtitle = "Les points ne représentent pas l'étendue des zones inondées"
  )

Limites et précautions

  • Les points ne délimitent pas les zones inondées.
  • Les observations documentées ne forment pas un échantillon probabiliste de toutes les inondations.
  • Les années avec peu ou pas de points ne doivent pas être interprétées seules.
  • Les comparaisons entre événements exigent de vérifier les rapports et les méthodes de collecte.
  • Toute communication publique doit distinguer observation ponctuelle, niveau maximal, niveau observé et risque territorial.

Extensions

  • Lire le GeoJSON officiel avec sf.
  • Joindre les points à des régions administratives ou à des bassins versants.
  • Comparer les observations MAX et ACT par année.
  • Construire une carte interactive avec une fenêtre de contexte par rapport.
  • Rédiger une note de vulgarisation sur les limites d’une carte de points en sécurité civile.
