Pourquoi ce jeu est intéressant

Ce jeu peut servir à enseigner la prudence avec les données de sécurité publique : catégories administratives, dates, quarts, postes de quartier, localisation partielle, agrégation et risques de surinterprétation.

L’intérêt pédagogique n’est pas de produire un classement de quartiers. Il est plutôt de montrer qu’une analyse descriptive responsable commence par l’unité statistique, la source, la portée officielle, les valeurs manquantes et les limites éthiques.

Question d’analyse : que peut-on décrire sans transformer ces données ouvertes en statistiques officielles de la criminalité?

La description officielle indique que le jeu contient une liste d’actes criminels enregistrés par le SPVM. Elle précise aussi que ces données ne représentent pas les statistiques officielles du SPVM et renvoie au bilan mensuel de la criminalité pour un portrait mensuel officiel.

Ce que représente une ligne

Une ligne représente un acte criminel enregistré dans le jeu publié. Elle contient une catégorie, une date, un quart de journée, un poste de quartier et, lorsque disponible, une localisation.

Une ligne n’est pas une personne, une accusation, une condamnation, une victimisation, une mesure de risque individuel, ni une statistique officielle complète de la criminalité.

Lecture statistique

Une analyse prudente suit cet ordre :

  1. rappeler que la source ne constitue pas les statistiques officielles du SPVM;
  2. définir l’unité comme un acte enregistré dans le fichier ouvert;
  3. choisir une période comparable, surtout si 2026 est inclus;
  4. agréger par mois, année ou catégorie avant de visualiser;
  5. éviter les cartes de points bruts et les classements de quartiers;
  6. accompagner chaque résultat d’une limite sur la déclaration, l’enregistrement et la publication.

Les données permettent de produire des descriptions agrégées. Elles ne permettent pas, seules, d’inférer le niveau réel de criminalité, de comparer la sécurité des quartiers ou d’attribuer des causes.

Concepts enseignables

  • données sensibles;
  • unité statistique;
  • catégories administratives;
  • agrégation temporelle;
  • valeurs manquantes;
  • visualisation responsable;
  • biais de déclaration;
  • communication des limites.

Activité courte

En 30 à 45 minutes, produire un résumé par catégorie et rédiger une note sur les limites de la source.

Activité longue

En 2 à 3 heures, produire un rapport descriptif par mois et catégorie, avec une visualisation agrégée et une section éthique au même niveau que les résultats.

Code R minimal

À exécuter depuis la racine du projet.

# Load libraries
library(dplyr)
library(ggplot2)
library(readr)

# Download and prepare official CSV resource
source("datasets/actes-criminels-montreal/preparation.R")

# Import prepared data
actes <- read_csv(
  "data/processed/actes-criminels-montreal/actes_criminels_montreal.csv",
  show_col_types = FALSE
)

# Summarise by month and category
resume_mois <- actes |>
  group_by(mois, categorie) |>
  summarise(n_actes = n(), .groups = "drop")

resume_mois

# Visualise without mapping individual points
ggplot(resume_mois, aes(x = mois, y = n_actes, color = categorie, group = categorie)) +
  geom_line() +
  labs(
    x = "Mois",
    y = "Nombre d'actes enregistrés",
    color = "Catégorie",
    title = "Actes criminels enregistrés par mois et catégorie",
    subtitle = "Données ouvertes du SPVM; ne pas interpréter comme statistiques officielles"
  ) +
  theme(axis.text.x = element_text(angle = 90, hjust = 1))

Limites et précautions

  • Le jeu ne représente pas les statistiques officielles du SPVM selon la description Données Québec.
  • Les données de sécurité publique peuvent renforcer des interprétations stigmatisantes si elles sont mal contextualisées.
  • Les cartes de points bruts sont à éviter dans un contexte pédagogique.
  • Les coordonnées sont manquantes pour 58 974 lignes dans le CSV téléchargé le 2026-06-21.
  • Une variation observée dans le fichier peut refléter des changements de déclaration, d’enregistrement, de publication ou de contexte.
  • Une comparaison territoriale exige un dénominateur, une période comparable, une géographie définie et une discussion éthique.

Extensions

  • Agréger par mois et catégorie, puis exclure les années partielles dans une comparaison annuelle.
  • Comparer les résultats ouverts avec le bilan mensuel officiel lorsque la question porte sur un portrait officiel.
  • Construire une carte en grille ou par zone agrégée, sans afficher les points individuels.
  • Rédiger une note méthodologique expliquant pourquoi un classement de quartiers serait trompeur.
