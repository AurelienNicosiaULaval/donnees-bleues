Pourquoi ce jeu est intéressant

Ce jeu de données place les personnes étudiantes devant une source québécoise réaliste : des écoles publiques, des immeubles scolaires, des coordonnées géographiques, des régions administratives et plusieurs décisions de comptage qui changent l’interprétation.

La fiche porte sur la ressource CSV Écoles publiques du paquet Données Québec. Ce choix rend l’activité reproductible, parce que la ressource est directement lisible en R sans logiciel géomatique.

Question d’analyse : comment cartographier les écoles publiques du Québec sans confondre une école, un immeuble et un lien école-immeuble?

Ce que représente une ligne

Une ligne représente un lien entre une école publique et un immeuble scolaire. Ce n’est pas exactement une école unique. La description officielle précise qu’une école peut utiliser plusieurs immeubles pour dispenser son enseignement et qu’un immeuble peut accueillir plusieurs écoles différentes.

Cette distinction est l’intérêt statistique principal de la fiche. Selon le regroupement choisi, on peut compter :

  • les 5 466 liens école-immeuble;
  • les 2 777 organismes scolaires distincts;
  • les 3 610 immeubles scolaires distincts;
  • les 72 centres de services scolaires ou commissions scolaires;
  • les 17 régions administratives.

Ces nombres ne répondent pas à la même question. Une carte de points construite à partir de toutes les lignes montre des liens école-immeuble, pas directement une carte des écoles uniques.

Lecture statistique

La première décision d’analyse est le dénominateur. Si on compte les lignes, on compte des liens école-immeuble. Si on veut compter des écoles, il faut regrouper par CD_ORGNS. Si on veut compter des bâtiments, il faut regrouper par CD_IMM.

La question “quelle région est la mieux desservie?” ne peut pas être tranchée avec ce fichier seul. Il manque au minimum une population scolaire, une population totale, la superficie, les distances de déplacement ou la capacité des établissements. La fiche peut donc soutenir une analyse descriptive de localisation, mais pas une mesure complète d’accès à l’école.

La colonne officielle COMBINE_NUO_NUI est vide dans le CSV consulté le 2026-06-20. Je ne sais pas pourquoi cette colonne est vide. Le script de préparation crée donc lien_ecole_immeuble_id à partir de CD_ORGNS et CD_IMM, et vérifie que cet identifiant est unique.

Activité courte

En 60 à 90 minutes, demander aux personnes étudiantes de distinguer un lien école-immeuble, un organisme et un immeuble. Elles doivent ensuite produire un graphique des comptes par région et une carte simple des coordonnées.

Activité longue

En 2 à 3 heures, demander un mini-rapport reproductible avec une carte, deux regroupements territoriaux et une section qui explique pourquoi les comptes ne mesurent pas directement l’accès à l’école.

Questions pédagogiques possibles

  1. Quelle est l’unité statistique de la ressource Écoles publiques?
  2. Pourquoi le nombre de lignes est-il différent du nombre d’organismes scolaires?
  3. Pourquoi le nombre d’immeubles est-il différent du nombre d’écoles?
  4. Quelle variable faut-il utiliser pour compter les organismes?
  5. Quelle variable faut-il utiliser pour compter les immeubles?
  6. Pourquoi les comptes par région ne sont-ils pas des taux de desserte?
  7. Quelle information manque pour parler d’accès géographique à l’école?
  8. Comment présenter une carte sans surinterpréter les concentrations de points?

Code R minimal

library(dplyr)
library(ggplot2)
library(readr)

url <- "https://www.donneesquebec.ca/recherche/dataset/2d3b5cf8-b347-49c7-ad3b-bd6a9c15e443/resource/c6640a54-bc4b-43ec-864e-6c325dce61bc/download/pps_public_ecole.csv"

ecoles <- read_csv(url, show_col_types = FALSE) |>
  mutate(
    lien_ecole_immeuble_id = paste(CD_ORGNS, CD_IMM, sep = "-"),
    longitude = COORD_X_LL84_IMM,
    latitude = COORD_Y_LL84_IMM,
    region_administrative = NOM_REG_ADM,
    type_reseau_public = case_when(
      TYPE_CS == "Franco" ~ "Francophone",
      TYPE_CS == "Anglo" ~ "Anglophone",
      TYPE_CS == "Statut" ~ "Statut particulier",
      TRUE ~ TYPE_CS
    )
  )

ecoles |>
  summarise(
    liens_ecole_immeuble = n(),
    organismes = n_distinct(CD_ORGNS),
    immeubles = n_distinct(CD_IMM),
    regions = n_distinct(region_administrative)
  )

ecoles |>
  count(region_administrative, sort = TRUE)

ecoles |>
  ggplot(aes(x = longitude, y = latitude, color = type_reseau_public)) +
  geom_point(alpha = 0.45, size = 0.8) +
  coord_quickmap() +
  labs(
    x = "Longitude",
    y = "Latitude",
    color = "Réseau",
    title = "Liens école-immeuble du réseau public québécois"
  )

Limites et précautions

  • Une ligne représente un lien école-immeuble, pas automatiquement une école unique.
  • Les noms et adresses d’écoles sont publics, mais ne doivent pas être mis en évidence inutilement.
  • Les comptes par région ne tiennent pas compte de la population, de la superficie, de la distance ou de la capacité.
  • Les coordonnées représentent les immeubles scolaires, pas les lieux de résidence des élèves.
  • Une carte de points peut donner une impression de densité qui dépend surtout de la population et de l’urbanisation.
  • Aucune conclusion causale ou normative ne doit être tirée sans données complémentaires.

Extensions

  • Extension intro : comparer le nombre de lignes, d’organismes et d’immeubles.
  • Extension visualisation : produire une carte de points par type de réseau public.
  • Extension jointure : joindre un tableau de population régionale et calculer un ratio descriptif.
  • Extension spatial : transformer les coordonnées en objet sf et projeter au Québec.
  • Extension communication : rédiger une note qui explique pourquoi une carte ne mesure pas directement l’accès scolaire.
